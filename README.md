# 都道府県名・県庁所在地 漢字入力クイズ

白地図で赤く塗られた都道府県を見て、都道府県名と県庁所在地をどちらも漢字で入力する学習用クイズです。

## 公開方法（GitHub Pages）

1. GitHubで `prefecture-quiz` などの新しいリポジトリを作成
2. このフォルダ内の `index.html` と `map-full.svg` をアップロード
3. Repository Settings → Pages
4. Source: `Deploy from a branch`
5. Branch: `main` / Folder: `/root`
6. 保存して数分待つ

公開URL例：

```text
https://tk50175280.github.io/prefecture-quiz/
```

## ファイル

- `index.html` : クイズ本体
- `map-full.svg` : 日本地図SVG
